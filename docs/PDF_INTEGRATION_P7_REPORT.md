# P7 export lifecycle

Completed October 29, 2026. New preview, confirmation, history, download, provenance and pending-recovery routes remain isolated from existing PDF/template exports.

Scope decisions, configuration and saved inspection/checklist/manual/point/event data are resolved within one database-enforced read snapshot. Confirmation repeats that snapshot and compares the complete frozen context, exact version/configuration, scope decision, requester, renderer and retained preview hash. Tokens are hashed in storage and sent only in POST bodies. Source/configuration changes, forged/expired proofs, unsaved browser edits and unsupported policies block confirmation. Ordinary edits after the accepted snapshot cannot change its frozen final. Preview operations do not accept point/event decisions or modify inspection answers.

Final request IDs produce deterministic private artifact IDs under a requester/inspection namespace, giving database-enforced retry/concurrency idempotency without schema changes. Explicit later requests retain separate immutable artifacts. Pending records commit before bounded rendering and private atomic publication; sealing is a separate transaction. A database failure after file retention leaves a non-downloadable pending record. Authorized recovery regenerates frozen bytes, verifies an existing file instead of replacing it, and seals the same record after a two-minute processing lease. Rendering/storage failures retain failed states. Ready downloads verify stored hashes; disabled integrations do not erase historical downloads.

The completed renderer creates a fresh page tree containing only selected background drawing content and occurrence-specific validated overlays. It clears widget values/appearances, omits forms/actions/attachments and excluded pages, validates glyph/layout/state/geometry and output structure, and uses 1.2-line spacing consistently with readiness checks. Previews have a visible diagonal DRAFT watermark; finals have no feasibility/draft watermark. NFPA includes exactly pages 1–4; Compliance includes one page. Explicit empty answer-group choices represent clearing a standalone NA marker; no missing answer becomes a passing result. Editable PDF combo boxes accept custom text; closed choices still require declared options.

Download naming must be explicitly configured (`completion_date_panel_id`); existing published configurations with no approved policy cannot export. Saved completion dates and an explicit panel ID disambiguator determine sanitized filenames, with UUID private keys preventing overwrites. Technician provenance redacts private storage paths while retained internal snapshots preserve source evidence. Explicit bounded maintenance removes only expired previews older than a day beyond expiry and records cleanup, preserving originals, final files and audit history.

The technician UI previews, confirms, downloads and lists retained exports, reports stale/failed/pending requests and provides recovery/provenance links. It protects unsaved existing Store Data/checklist/point edits as well as Form Details. Existing saves and exports remain independent.

Verification: 22 export lifecycle cases passed across SQLite and PostgreSQL, including HTTP authorization/forgery/header/path checks, four-page NFPA selection, corruption, concurrent retries, frozen post-acceptance changes, disablement, renderer failure, database/file split failure and recovery, and bounded preview cleanup. Domain/source/storage batches passed (75 cases before final additional cases; latest mapping/readiness batch 13 passed). Chromium completed the stale-preview → fresh preview → final download → history journey and inspected actual downloaded PDF text. Full regression and private supplied-form rendering are P9 evidence.

The user deferred production defaults and requested adjustability. P8 installs reviewed technical draft candidates only; company constants, categories/timezones and business policies are not inferred from supplied presets. Mapping publication/enablement remains an administrator action. No production deployment occurred during P7.
